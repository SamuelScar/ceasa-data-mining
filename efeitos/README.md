# Efeitos estudados

Esta pasta concentra o código e a documentação de cada efeito analisado:

- `domino`: caracterização já implementada a partir das relações de Granger;
- `foguete_pena`: reservado para o estudo de assimetria entre altas e quedas;
- `volatilidade`: reservado para o estudo de períodos de maior oscilação.

Os arquivos produzidos por essas etapas ficam em `resultados/efeitos/`.
